# 功能介绍

VC Hunter 的核心流程是“发现线索 → 留存来源 → 人工复核 → 建立项目 → 研究与协作 → 沉淀知识”。公开搜索、模型摘要和人工判断分别记录，便于回溯结论从何而来。

## 1. 发现与候选

“项目发现”支持手工录入候选、公开网络搜索、已批准 RSS/Atom 信源采集，以及一次性或定时发现计划。候选可附原件和来源地址；搜索结果不会直接成为正式项目或事实。复核人确认名称、赛道、资料和来源后，才可将候选纳入项目库。

## 2. 项目全生命周期

项目页汇集状态、负责人、阶段、里程碑、评论、时间线和资料。团队可上传 PDF、DOCX、TXT、Markdown 文件，在线预览或下载原件，并在资料上批注、审核或要求修改。阶段推进、负责人分配和人工判断都有版本冲突保护与操作记录。

## 3. 证据化投研

系统区分来源文档、证据片段、事实断言、推断和研究报告。未知或未披露字段有独立状态；冲突来源并存，交由人工复核。研究 Profile、Skill 和后台工作流帮助收集、清洗、分析并产出草稿，但不替代投资决策。

## 4. 机构、人才与知识

机构库和投资事件支持项目关联与历史观察；人才信号用于提示进一步核实的方向。知识卡记录主题、来源和审核状态。公开线索不自动升级为高等级告警。

## 5. 团队协作与业务台账

工作台提供待办、通知、日程和讨论。审批事项可附资料，指定审核人处理；基金、财务、合同、联系人与专家记录支持检索、编辑和归档。付款字段仅用于登记，不执行转账。

## 6. 组织架构与像素办公室

组织架构页提供部门与成员目录；团队办公室可在传统列表和像素视图之间切换，按部门或项目查看工位。成员可调整自己的工位外观和展示信息，头像经审核后才会出现在办公室。待处理沟通和会议状态可在地图中显示；管理员可调整布局。

## 7. 个人 AI 与后台任务

成员可在“设置”中配置个人模型，并在项目资料范围内提问。服务端按账号保存加密后的密钥，不向页面回传原文。问答显示引用来源，运行历史按账号和项目隔离。后台 Agent 根据已配置计划领取搜索或研究任务，保留版本、耗时和执行状态；无模型或搜索凭据时相关步骤不可用。

## 8. 服务器部署与终端适配

系统可部署在服务器，支持数百名成员使用同一团队工作空间。界面采用响应式布局，通过现代浏览器在 Windows、macOS、Linux、iOS 和 Android 上访问；移动端提供独立导航。这里的跨平台适配指 Web 使用，不代表提供原生桌面或手机安装包。

团队环境需要登录认证、HTTPS、持久化存储和备份。当前业务存储使用单工作空间 SQLite；数百人是用户规模描述，具体同时在线人数与高负载处理能力须按目标环境压测确认。

## 当前边界

- 默认本机模式使用 SQLite 和演示身份；团队部署需要显式启用登录和配置 HTTPS。
- 外部信息及模型输出需要回到原始来源核验。
- 个人模型是否可用取决于服务商账号、额度和接口权限。
- 多机构规模化部署、完整多租户业务隔离、多因素认证及生产运维方案需另行设计与验收。
